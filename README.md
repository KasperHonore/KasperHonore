# Hi, I'm Kasper 👋

I've been pushing technology to its limits since my first Raspberry Pi. I'm a product developer by background, and I always had more ideas than software skills. AI changed that. Now I build the things I used to only sketch.

## How I approach things

I start with the problem, not the tech. What's the root cause, and is it worth solving at all? Throwing AI at everything isn't a strategy. If solving it won't create value, whether that's revenue, happier customers or a better workday, I leave it alone.

## What I'm into

- How AI changes the way teams work
- Self-hosting and owning my own stack
- Away from the keyboard: gaming and cooking

## Own your stuff

Self-hosting started as curiosity and turned into something I care about. My photos, my data and my tools live on hardware I own, and if I don't like how something works, I change it. With AI, shaping your own tools has never been cheaper or more fun, even if you're not a developer.
